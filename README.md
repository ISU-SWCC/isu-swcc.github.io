# SWCC DEM tiles

Elevation tiles for the watershed order page at https://isu-swcc.github.io/pages/watershed-model.html.

These files are Copernicus DEM GLO-30, packed as 8-bit RGB PNGs. The red byte is the high half of the stored value and the green byte is the low half. Subtract 500 to get meters. 65535 is nodata. This branch is not the public website.

The 250 m set covers the US watershed search area. Ocean tiles are omitted.
